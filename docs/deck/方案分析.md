> 状态：方案分析，未动产品代码
> 分支：`deck`
> 视觉草案：[`proto-deck.html`](proto-deck.html)（单文件、0 位图、1040×538 设计稿，**不是**产品代码）
> 参考对象拆解：[`参考对象-REPLAY官网拆解.md`](参考对象-REPLAY官网拆解.md)
> 实现路径细化：[`实现路径.md`](实现路径.md)（DOM 改造点、高度预算、仪表公式、验收命令）（对方无 LICENSE，只参考思路与几何参数，不复制代码/素材）

参照形态：RE:PLAY「THE CASSETTE EXPERIENCE」——磁带机面板：卡带窗、双卷盘走带、双 VU 表、LED 频谱、四旋钮、调谐条。

---

## 1. 结论先行

- **落位推荐 B：把现有底部 dock 升级成「可展开两层」**。收起态 = 现在的 86px 播放条，展开态 = 约 300px 的磁带机面板。理由：试听是「看和听」的加强，不是新流程；常驻或独立页都会挤掉三栏主区。
- **改动集中在三处**：`index.html`（结构）、`app.css`（样式）、新增 `web_ui/deck.js`（走带/表头）。`viz.js` 基本不动，**只多加两个只读接口**（`analyser()` / `rms()`），不另建 AudioContext。
- **风险最高的不是视觉，是音频图**：`viz.js` 里那条 `src → analyser → destination` 的连接是「断开就静音」的硬约束（源码注释里已经踩过）。BASS/TREBLE 要插 BiquadFilter，必须在这一条链上改，不能新开一条。

## 2. 目标与非目标

**目标**

| # | 目标 | 判定标准 |
|---|---|---|
| G1 | 试听区有磁带机形态（卡带、卷盘、VU、LED 频谱、旋钮） | 与草案视觉一致，肉眼可辨 |
| G2 | 0 位图 | 只用 CSS 渐变 + inline SVG，仓库现有约束 |
| G3 | 与 6 套复古主题共存不脏 | 容器色取 `var(--*)`；材质色固定 Gold / Retro 两套（见 §9-3） |
| G4 | 收起态不牺牲现有功能 | 「开始转换」按钮、时间码、进度条位置不变 |

**非目标**

- 不做 3D / WebGL / 视频素材；
- 不引入构建工具，仍是 `<script>` 直引，风格与 `app.js`（ES5 + 少量 ES6）一致；
- 不动转换、下载、云上传主流程；
- 不做移动端布局（桌面 WebView 固定，最小 1200px）。

| 资产 | 位置 | 现状 | 改造中能否复用 |
|---|---|---|---|

## 4. 落位方案对比

| | A 直接替换 dock | **B dock 可展开（推荐）** | C 独立第三页 / 弹层 |
|---|---|---|---|
| 改 HTML | 大（dock 整块重写） | 中（dock 外套一层，内部分两段） | 大（新页面或遮罩层） |
| 对主区影响 | 常驻占高，三栏被压 | 收起时零影响 | 展开时遮挡主区 |
| 转换按钮位置 | 需挪，用户习惯被打断 | 收起态原位不动 | 需另找位置 |
| 实现复杂度 | 中 | 中 | 高（路由/状态同步） |
| 回滚成本 | 高 | 低（删一段 DOM 即回到现状） | 高 |
| 结论 | 否 | **采用** | 次选 |

选 B 的核心理由：**deck 是「想细看的时候点开」，不是工作台主界面**。转换才是主流程，播放条只要在，用户不会迷路。

## 5. 推荐方案的形态设计

### 5.1 结构

```
┌──────────────────────── dock（收起态，86px，沿用现有 grid）────────────────────────┐
│ [封面] 曲名/元信息 │ ◀ ▶ ▶ │ ── 进度条 ── │ 0:12/1:40 │ 🔊 音量 │  开始转换  │ ▴ 展开 │
└──────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────── deck（展开态，≈300px，向上生长）───────────────────────────┐
│ ┌─卡带窗──────────────┐ ┌─走带控制──────────┐ ┌─仪表区───────────────┐            │
│ │  ● 卷盘L   卷盘R ●  │ │  ▮ 播放 ▮ 停止     │ │  VU L   VU R          │            │
│ │  磁带标签（曲名）    │ │  LCD 时间码        │ │  15 列 LED 频谱       │            │
│ │  走带口 / 螺丝       │ │  [◀◀] [▶] [▶▶]     │ │  BASS / TREBLE        │            │
│ └────────────────────┘ └───────────────────┘ │  VOLUME / POWER       │            │
│                                              └───────────────────────┘            │
│  ── 调谐条（刻度 + 指针 = 播放进度）────────────────────────────────────────────    │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 元素语义映射（**不许造假数值**）

| 参照元素 | 本项目映射 | 数据来源 |
|---|---|---|
| 双卷盘 | 左盘半径随进度变小、右盘变大，转动角速度 ∝ 剩余时长 | `audio.currentTime / duration`；卷盘图案放 `<g>` 上直接 `rotate()`，不必重绘整图 |
| LCD 时间码 | 现有 `#tcNow` | `timeupdate` |
| VU 双表 | 实时 RMS，-48…0 dB 映射到 -42°…+42°，带峰值保持回落 | `AnalyserNode.getByteTimeDomainData` |
| 15 列 LED 频谱 | 把 48 柱的对数取样结果聚合成 15 列（每列取 max） | 复用 `viz.js` 的取样公式 |
| BASS / TREBLE | 试听用的 `lowshelf` / `highshelf`，**只影响试听，不写入导出** | BiquadFilterNode |
| VOLUME | 接管现有 `.vol-slider`（`app.js:927` 的 `audio.volume`） | 同一变量，单一真相 |
| TUNING | **建议砍掉或改 SPEED（0.5–2.0×，仅试听）**——调谐对本工具没有语义，摆着就是假旋钮 | `audio.playbackRate` |
| POWER | 试听总开关（等价于暂停 + 面板断电熄灯） | — |

> 「假表最伤产品」：草案里的 TUNING 是纯装饰。要么给它真实语义（播放速率），要么删。二选一必须定。

## 7. 关键技术点

1. **AudioContext 只能有一个，`createMediaElementSource` 对同一元素只能调一次**（`viz.js:151-177`，注释里①写得很清楚）。deck 必须从 viz 拿 `V.an`，不能自己 `new AudioContext()`，否则第二次调用直接抛 `InvalidStateError`。
2. **插 BiquadFilter 必须原地改链**：现状是 `src → analyser → destination`，且注释明确「这条连接永远不断开」。加 BASS/TREBLE 后应为 `src → lowshelf → highshelf → analyser → destination`，旧连接先 `disconnect()` 再重连，**不能并存两条链**（两条链会导致双倍音量/相位问题）。
3. **尺寸适配：内层锁比例 + 百分比坐标**（参考对象已验证的做法）。外层 `#deck` 走 `--dock-h: clamp(236px, 32vh, 386px)`（含 86px 收起条，见[实现路径](实现路径.md) §1）；里面的面板组（卡带窗 + 仪表区）用 `aspect-ratio: 1040 / 538` 锁比例，宽度取 `min(100%, 设计稿宽)`，**内部所有部件按百分比绝对定位**，任意窗口宽度下都不错位。两条别走：`transform: scale()`（canvas 变糊、旋钮命中区偏移）、CSS 变量 `--k` 逐个算尺寸（等于自己写一套布局引擎）。实际可用宽度 = 视口 − 260（左栏）− 340（右栏）。
4. **只跑一个 rAF**：viz 已经在循环，deck 的卷盘/VU 用同一帧时间戳更新，避免双循环抢帧；面板收起或暂停时停表（沿用 `viz.stop()` 的语义）。
5. **颜色只取变量**：`--accent` / `--accent-2` / `--surface` / `--border-2`。VU 表盘的米黄、卡带壳的砖红这类「材质色」定义为局部变量，**只给 Gold / Retro 两套值**（与 §9 第 3 条一致，不跟全局 6 主题），不写死在选择器里。

## 8. 风险清单

| 风险 | 触发条件 | 影响 | 对策 |
|---|---|---|---|
| 展开后挤压主区 | 窗口高度 < 800px | 三栏内容被裁 | 主区三栏本身都能内部滚动（`.rail` / `.inspector` 有 `overflow-y:auto`），行高变化不会压坏内容；高度按 `clamp(236px, 32vh, 386px)` 收敛 |
| 动了音频图导致静音 | 忘记 `connect(ctx.destination)` | 频谱正常但没声音（历史坑） | 改完先跑「有声 + 有表」双检查；这段逻辑集中在 viz.js 一处 |
| 新静态文件没打包 | 只在 `build_web_pyi.py` 加了，漏 `build_web.py` | 只有 PyInstaller 版 404，Nuitka 版正常 | 两处清单同步改，P3 用 exe 实机验一次 |
| 两套取样逻辑漂移 | 15 列频谱另写一份 bin 取样 | 两处频谱形状不一致 | 取样公式只在 viz.js 里，deck 只做聚合 |
| 小屏溢出 | 宽度 < 1200px | 旋钮/表盘重叠 | 媒体查询：只保留卡带 + VU，隐藏旋钮组 |
| 参考对象素材误入 | 有人顺手扒对方图片/代码 | 对方无 LICENSE，默认保留所有权利 | 只参考思路与几何参数；来源不明的二进制一律不进仓库 |
