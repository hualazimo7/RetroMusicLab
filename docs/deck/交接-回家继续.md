## 5. 已核实的代码事实（不要重查，直接用）

改代码前先接受这些前提，它们都是一行行看出来的：

**1. 全库没有任何 DSP 节点。**
音频链只有 `viz.js:161-168` 三个节点：`src → analyser → destination`。grep 不到任何
`BiquadFilter` / `Compressor` / `Gain`。加效果全是新增，不存在"改参数"的省事路径。

**2. 音量目前走元素，不走节点。**
`app.js:927`：`audio.volume = vol.value / 100`。
一旦引入音量 GainNode，就会有两个乘数相乘。**必须把 `audio.volume` 固定为 1.0**，
并同步改掉 `download.js:391` 那条旧注释，否则下一个人会按旧注释改回来。

**3. `new AudioContext()` 与素材采样率不一致。**
全库 8 处 `OUT_RATE = 44100`（`cd_audio.py:53`、`mod_audio.py:49` 等），
而浏览器实际多半跑 48000。自生成 IR 必须用 `ctx.sampleRate` 算长度，不能写死 44100。
界面上写 44100 是对的（那是产物格式），别抄成 48000。

**4. dock 行高 86px，左栏 260px。**
`app.css:142` 是 `grid-template-rows: 50px minmax(0, 1fr) 86px`；
`app.css:229` 是 `grid-template-columns: 260px minmax(0, 1fr) 340px`。
（早先文档里写的 72px / 232px 是错的，232 是 dock 自己第一列的宽度。）

**5. 三栏都能内部滚动，所以主区变矮不会压坏内容。**
`.src-list`（`app.css:301-304`）、`.inspector`（`app.css:614-619`）、`.stage`（`app.css:409` `min-height:0`）。

**6. `viz.js:284` 有个语义坑。**
```js
function loop() {
  if (!V.on) { V.raf = 0; return; }   // ← 关掉可视化开关，整条循环就死了
```
任何挂在同一条 rAF 上的东西（VU 表针、deck 卷盘、EQ 曲线）都会跟着僵住。
接新动画之前必须把语义改成「`V.on` 只决定画不画 canvas，不决定跑不跑循环」。

**7. 主题是 inline 变量注入，不是 class 切换。**
`theme.js` 把 6 套复古配色的变量 `style.setProperty` 写进 `<html>`，
`server.py` 的 `_palette_vars()`（约第 998 行）连 `--accent-soft`、`--accent-line` 都算好了。
所以 **SVG 里写 `stroke="var(--accent)"` 在 8 套外观下自动正确**，
而 Canvas 必须像 `viz.js:187` 那样每 500ms 重读 `getComputedStyle`。这是选 SVG 的决定性理由。

**8. 频谱 canvas 搬家是安全的。**
`app.css:770` 的 `.viz-wrap > canvas` 是**结构选择器**，搬到哪都生效；
`test_web_ui.py:3678` 只断言 `id="vizWrap"` 存在，不看层级；
`check_web_exe.py:416` 只查 `index.html` 字节里有没有 `vizCanvas`。

**9. 后端已经具备 AI 母带所需的一切。**
`numpy==2.5.4` 已在 `requirements.txt`，`build_web_pyi.py` 的 `COLLECT_ALL` 也保留了它；
`/api/audio` 的 `_send_wav`（`server.py:1642`）支持 Range/206（但本方案用不上，分析放 Python 侧更省内存）；
路径校验照抄 `_audio()` 的 `state.find_output`（`server.py:1629`），不接受任意路径。

**10. 导出链路完全在 Python 侧。**
Web 端只播 `/api/audio` 的产物。因此**所有试听侧处理（EQ / 母带 / 空间）都不会影响导出文件** ——
这是设计上刻意保留的口径，不要试图让它们同步。

## 7. 已被推翻的旧结论（别按这些做）

| 旧结论 | 现在 | 原因 |
|---|---|---|
| 缩放用 `transform: scale()` | 改 `aspect-ratio` + 百分比绝对定位 | 参考实现在真实产品上验证过；scale 会让 canvas 变糊、命中区偏移 |
| dock 展开就够（改 `.app` 行高） | 双风格下改为中间栏 PlayerView | 极光竖向布局放不进 300px 高的条 |
| dock 高 72px / 左栏 232px | **86px / 260px** | 读错行，实际见 §5-4 |
| 输出设备切换「浏览器拿不到」 | 有条件可做 | `AudioContext.setSinkId()` Chromium 110+ 可用。真限制是：图接管后元素级失效、无麦克风权限时拿不到设备名 |
| 9 段 EQ 降为 3 段 | **做 9 段**，幅度 ±6dB | 参考产品就是 9 段 |
| AI 会顺手调压缩/开关 | **AI 只给音色曲线，开关全归用户** | 用户明确要求；`/api/tone` 刻意不返回 `flags` 字段防后患 |
| 播放中在 EQ 曲线下叠淡频谱 | 撤销 | 点阵频谱已经表达同一件事，重复 |
| 极光要歌词 / 电台 / AI 懂你 | **全不做** | 用户明确收窄范围，只做播放器功能 |

## 8. 三条不变量（写在皮肤契约里，机械可检）

1. **皮肤不碰音频。** `grep -l "createMediaElementSource\|AudioContext" skin_*.js` 必须为空。
2. **皮肤不建 DSP 节点。** `grep -l "createBiquadFilter\|createDynamicsCompressor" skin_*.js` 必须为空。
3. **皮肤不直接写 `param.value`。** 只能通过 `Core.tone.set*()`；机械检查是 `grep "\.value\s*=" skin_*.js` 只允许出现在非 AudioParam 上。

音色引擎属**内核**（`Core.tone`），不属皮肤。Deck 的两颗旋钮和极光的 6 预设 + 9 段 + 4 开关改的是同一份参数，
切皮肤时音色不丢、不重算、不爆音。

## 11. 边界

- **参考对象均无 LICENSE**（`replay-cassette-player-site`、`AURORA_Player`、`auroraplay-releases`）。
  只参考思路、几何参数、观感数值，**不复制代码、不复制素材**。

- 反编译产物不进仓库、不进 exe、不上传云端。
- 对外命名用「极光」/ 内部代号 `aurora`，不用对方的 `AURORA` 名称与 logo。
- 「AI 母带」可以说「按音源频谱自动匹配」「本地计算不上传」，
  **不能说**「学习听歌习惯」「越用越懂你」。技术上它是规则引擎，好处是确定性：同一文件永远同一套参数。
