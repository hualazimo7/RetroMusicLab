# 更新说明 v1.0 —— 品牌统一为 RetroMusicLab

> 一句话：**程序改名叫 `RetroMusicLab.exe`，官网版本号从 6.0.12 起改用 1.0 语义。
> 功能与 6.0.12 完全一致。**

---

## 1. 这一版改了什么

| 项 | 旧 | 新 |
|---|---|---|
| 程序名 | `MSU1Converter-web.exe` | **`RetroMusicLab.exe`** |
| 发布包 | `MSU1Converter-v6.0.12-web-win64.zip` | **`RetroMusicLab-v1.0-win64.zip`** |
| 对外版本 | 6.0.12 | **1.0** |
| 仓库 | `hualazimo7/MSU1Converter` | **`hualazimo7/RetroMusicLab`**（旧地址自动跳转） |
| 界面标题 | RetroMusic Lab · 游戏音乐转换器 6.0.12 | RetroMusic Lab · 游戏音乐转换器 1.0 |

功能与 v6.0.12 **完全相同**，没有行为变更。这次只做品牌与版本语义的收敛：
对外用 1.0 作为首个公开版本，避免「刚发布就是 6.0.12」的困惑。

## 2. 版本号为什么有两个

- **产品版本 = 1.0**：界面、`/api/diag`、发布标签都用它。
- **编码器能力版本 = 6.0.12**：写在 WAV 元数据里，用来识别「v5.9.15~17 那批坏 MP3」。
  它必须保持 ≥ 5.9.18，**不能跟着产品版本降**，否则新转出来的 MP3 会被误判成旧坏文件。

普通用户只需要认 1.0。

## 3. 升级建议

- 直接下载新包解压，替换旧 exe 即可。
- 配置、登录态、试听列表仍保存在 `%LOCALAPPDATA%\MSU1Converter\`，**不会丢**。
- 下载目录、封面目录不受影响。
