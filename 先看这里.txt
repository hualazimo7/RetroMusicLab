**怎么运行**

直接双击 `MSU1Converter-web.exe` 就行。只有一个文件，不需要任何 bat 或脚本。
冷启动 2~3 秒（本机 NVMe），换到慢盘或开着实时扫描的杀软上可能要 20~60 秒，
这期间没有窗口、没有日志，属于正常现象，别急着判死。

`msu1-to-cd/dist/bios/` 是 PSF 用的 BIOS 副本，**跟 exe 放在同一个目录**即可
（程序会自动找到，不需要再手动指定）。

**加音源的两个入口**（左栏底部）

- `添加音源` —— 原生文件框，可多选文件
- `添加文件夹` —— 原生文件夹框，**含子目录**。规则：
  - 选中的文件夹本身就是一个「包」（PS1 下载包那堆 `.txtp`、MSU-1 的
    `.pcm` 包、一叠平铺的 `.spc`）→ **整个文件夹算一个音源**，曲目在右侧
    列表里，不会把 23 个 txtp 刷成一屏
  - 文件夹里套着若干子包 → 自动展开，一个子包一个音源
  - 递归深度上限 6 层，单次上限 5000 个音源

⚠ **拖放拿不到路径，这是浏览器的硬限制**：`File.path` 是 Electron 的私有
扩展，Chromium 从来没有过。我们是纯 Edge `--app` 窗口（不是 Electron），
所以 `f.path` 永远是 undefined —— 拖单个文件也一样失败，不只文件夹。
现在拖入后会**自动弹出原生选择框**并提示「浏览器不提供拖入文件夹的路径，
请在弹框里选同一个文件夹」，选一次就好。想一步到位就直接点 `添加文件夹`。

⚠ Web 版是「本地 HTTP 后端 + 浏览器应用窗口」，不是 Electron：
无地址栏/标签页，外观就是一个独立窗口。**不再只认 Edge**（v5.2.0.6）：
Edge → Chrome → Brave → Vivaldi（都是 Chromium，`--app` 外观完全一致）
→ 系统默认浏览器 → 内置 tkinter 界面（最后一条路，老界面但保证能开）。

## ⚠ 「双击没反应」怎么查（v5.2.0.6 起有日志了）

**先记住一个数**：本机（NVMe SSD）从双击到写出第一条日志是 **1.92 秒**，
其中 166MB 的自解压占了大头。换到慢盘 / 开着实时扫描的杀软上，这个时间会
线性放大到 **20~60 秒** —— 这期间没有窗口、没有日志、没有任何反馈，
和「彻底没反应」长得一模一样。**所以先等 30 秒，别急着判死。**

排查顺序（从快到慢）：

1. **先等满 30 秒**，然后看 `logs\startup.log` 有没有生成、最后一行是什么。
   有日志 = 程序在跑，只是窗口没弹出来（看日志里的「外壳浏览器 = 」那一行，
   浏览器找不到就会走到内置 tkinter 界面）。
2. **没有日志** → 打开任务管理器搜 `MSU1Converter-web`：
   - 进程在 → 卡在解压或杀软扫描，继续等，或把 exe 加进杀软白名单
   - 进程闪一下就没了 → 这台机器拦自解压（Smart App Control / 企业策略），
     关掉 SAC 或加白名单；改代码没用
3. **三处日志都没有** → `logs\`（exe 旁边）、`%LOCALAPPDATA%\RetroMusic Lab\logs\`、
   `%TEMP%\RetroMusic Lab\`，逐个看一遍。仍然没有就说明 Python 代码一行都没跑到。

窗口程序没有控制台，以前崩了就是「桌面闪一下什么都没发生」。现在每次启动都会写
**`<exe 旁边>\logs\startup.log`**（写不进去就退到 `%LOCALAPPDATA%\RetroMusic Lab\logs\`
或 `%TEMP%\RetroMusic Lab\`），里面每一步都有：

```
[17:07:57] 启动 MSU1Converter-web
[17:07:58] step: import msu1_to_cd
[17:07:58] step: 临时目录 = D:\MSU1Temp
[17:07:58] 服务已起：http://127.0.0.1:47913/
[17:07:58] 外壳浏览器 = Edge · C:\Program Files (x86)\Microsoft\Edge\...
[17:07:58] 拉起 msedge.exe --app=http://127.0.0.1:47913/
```

**最后一行的内容就是「走到哪一步」**。崩了还会弹一个消息框（含错误摘要 + 日志路径）。

两个命令行参数：

| 参数 | 作用 |
|---|---|
| `--console` | 临时开一个控制台，全过程都打出来（从 cmd 里跑效果最好） |
| `--tk` | 跳过浏览器，直接用内置 tkinter 界面（老界面，但零依赖） |

✅ **SPC 包转换不再「0% 卡住」（v5.9.5）**。
用户拿 92 首的 SPC 包（Chrono Trigger）点开始转换：进度一直 `0%`，日志停在
`▶ [1/1]`，CPU 却是满的 —— 看着就是死机。**两个原因叠在一起**：

1. **进度没接下去**。`load_source()` 的 `.spc` 目录分支是裸调 `load_spc_dir(path)`，
   `on_progress` 压根没传 —— 而 `load_spc_paths` 本身是支持的（每批结束都回调）。
   于是整个解码阶段一次上报都没有，进度条钉死在 0%。
2. **白解 4 倍时长**。默认策略 `natural` = 解到「连续 2 秒静音」为止；循环曲永远
   等不到静音 → 撞兜底上限 `_SPC_MAX_SECS = 600`（每首 10 分钟），而
   `write_tracks()` 随后只留前 150 秒 → **450 秒白解**。92 × 600 秒 = 15.3 小时音频。

修法：`on_progress` 接下去；新增 `decode_cap`（= 单曲最长 + **2 秒余量**）一路透传到
`--spc-cap`。**只当上限用**（`stop_on_silence` 不变），所以短曲照样按静音收尾，
成品**逐字节不变**。那 2 秒余量不能省：`_limit_len` 只在「超长」时才截断并加 1.5s 淡出，
正好解到 150 秒反而不触发截断、成品少一截淡出。

实测：8 首样本端到端 89.8s → **25.6s**；92 首整包解码 241.5s + 写盘 30s ≈ **4.6 分钟**
（旧逻辑约 17 分钟），8 个 WAV 的 md5 全同。

✅ **Capcom QSound 街机音源能转了（v5.9.10）**。
新增 `.qsf` / `.miniqsf`（CPS1 / CPS2 的街机 BGM）。用户给的样本是
`D:\MSU1Downloads\joshw\QSound 街机（Hoot）\Mega Man 2 - The Power Fighters …`，
45 首全部解码成功。

**QSF 是 PSF 家族的一员**（版本字节 `0x41`），和 PSF/USF/2SF/SSF/GSF 同一套思路：
里面没有波形，要跑模拟器。唯一区别是 program section 里放的不是可执行程序，
而是一串「11 字节块头 + 载荷」的**块**：`Z80`（程序 ROM）/ `SMP`（采样 ROM）/
`KEY`（CPS1 的 Kabuki 密钥）。`.miniqsf` 那 12 字节**不是程序、是补丁** ——
往 Z80 ROM 偏移 `0x21` 写一个字节（曲号），45 首的差异就只有这一个字节。

**⚠ 本轮真正的难点是采样率。** QSound 原生输出 **24038 Hz**，这个数不是笔误，
是 QSound DAC 的硬件节拍（`60000000/2/1248 = 24038.46`）——
混音器每输出一个样本就按它推进一次 DSP，**改大只会让整首变调**。
所以按「与其他机种一致」的要求，重采样放在解码器内部做：
64 抽头 Kaiser 加窗 sinc 多相 FIR（1024 相位、β=9、截止 0.45×源率、
32.32 定点累加、每相位归一化到直流增益 1）。出厂直接出 44100，
`spc_wav.write_tracks()` 那层一行都不用改。
代价是解码慢三分之一（62 分钟音频 38.7 秒 → 59.2 秒，96× → 63× 实时）。

**不需要 BIOS** —— QSound 是街机板上的独立声音子系统，没有主机 BIOS 这回事。
这条有门禁守着：`qsf_native` 里没有 `find_bios` / `set_bios` / `check_bios`，
diag 的 `qsf` 段没有 `bios` 字段，坏文件的报错文案**不许出现 BIOS**。

实测：45/45 成功、0 静音、peak 3,201~9,532（约 −10.7 dBFS）、
时长与 `length`+`fade` 标签全部一致（±20 ms）、同一首解两次逐字节相同。

接进了**四条**流水线（少一条就出「Web 能转、下载页转不了」那种老问题）：

✅ **下载页频谱面板修好了（v5.9.8）**。
用户报「可视化失效」并附了截图：歌在放（进度在走、有声音），但下载页右边

根因是**闭环正反馈**，跟音频、跟 Web Audio 一点关系都没有：

- `viz.js` 的 `resize()` 量 canvas 的 `getBoundingClientRect()`，乘 dpr 写回
  canvas 的 `width` / `height` **属性**；
- 而 canvas 的 CSS 尺寸在**没有任何样式约束**时，恰恰由这两个属性决定；
- → 300 → 375 → 469 → … 每帧 ×1.25（用户屏幕 dpr），60fps，

**ID 选择器**把尺寸钉死了；下载页的 canvas 叫 `#dlVizCanvas` —— 不匹配。

1. `app.css`：`#vizCanvas` → **`.viz-wrap > canvas`**（按结构选，两页一起覆盖）；
2. `viz.js`：`resize()` 改量 **`opt.wrap` 的 `clientWidth/clientHeight`**，与 canvas
   自身属性彻底解耦，链条直接断掉；
3. `viz.js`：加 `MAXPX = 4096` 钳制 —— 真失控了也只坏一块面板，不坏布局。
   另给 `.viz-wrap` 和 `.dl-viz` 补 `min-width: 0`（flex 子项默认 auto，会被顶破）。

⚠ **上一轮为什么没发现**：`_shot_v596.py` 只验了「canvas 两帧像素指纹不同 =
真的在动」—— 而**爆掉的 canvas 每帧也在变**，照样通过。教训：
验证「在动」不够，还得验「动得对不对」（尺寸是否合理）。
现在 `vendor/_probe_viz_fix.py` 直接量渲染尺寸，门禁里也加了 6 条静态断言
（结构选择器 / min-width / 量容器 / MAXPX），谁再动这块样式会当场红。

数据对比：canvas CSS 尺寸 **32545×16358 → 334×118**；面板 336 ≤ 侧栏 356；

✅ **KSS 换了解码器（v5.8）—— GG / SMS 那批有三成原来根本解不出来**：
libgme 的 KSS 实现**只映射 0x0000-0x3FFF 与 0x8000-0xBFFF，不映射 0x4000-0x7FFF**。
ROM 落在中间 16 KB 的 KSS（32 KB 的 GG rip 几乎都是）代码被丢掉一半，Z80 跑飞 ——
而 libgme **不报任何错**，每轨精确静音（peak == 0）。上层只能报

现在 `.kss` 走外挂解码器 `kss2wav.exe`（libkss，298 KB，zig 编），

⚠ 顺手修了 m3u 编码误判：原来「utf-8-sig → cp932 → latin-1，能解就用」，
但 **cp932 几乎不会失败**（单字节 0xA9 → 半角片假名 `ｩ`），zophar 的 latin-1 包
永远轮不到第三分支，曲名变成 `Puyo Puyo - ｩ1993` 还顺着进了文件名。现在是 `©1993`。

✅ **8 个机种的格式逐个盘完了**（v5.2.7）：`D:\MSU1Downloads\joshw`
下 8 个机种共 667 个文件（659 首曲目 + 8 个配套采样库），做到 **95 个**：

> ⚠ **下面这一节是 v5.2.7 的历史快照，其中「剩下 572 个做不到」的结论已被
> v5.3 / v5.4 / v5.5 推翻** —— 那些「内存快照」格式现在全部打通了（见本文上面
> 「v5.3 ~ v5.5 新增的格式」）。留着这一节只为说明 `.adx`/`.mod`/`.hwas`/`.swav`/`.dvi`
> 这 95 个是怎么来的。

| 格式 | 机种 | 数量 | 怎么解的 |
|---|---|---|---|
| `.adx` | Dreamcast | 7 | 转手 PyAV，一行没写 |
| `.MOD` | GBA | 10 | **自写 ProTracker 回放器 `mod_audio.py`** |
| `.hwas` | NDS | 29 | **自写 IMA ADPCM 解码器** |
| `.swav` | NDS | 4 | 同上（文件级一个 4 字节头） |
| `.dvi` | Saturn | 45 | 同上（高半字节先 + 4 字节交错） |

后三类是 v5.2.7 新攻下的 **78 个**。**不是「试着解」** —— 拿 vgmstream r2117
（业界标准实现）当黄金标准，把两边都转成 WAV **逐样本比对**，判据是**最大差必须为 0**：
78 个全部 100% 一致、最大差 0。纯 Python + numpy 写出来的和 C 实现的位级相同。

剩下 572 个是**真的做不到**，不是参数没调对：其中 494 个是 `.minigsf`/`.miniusf`/
`.mini2sf`/`.psf2`/`.dsf`，这些文件本身只有 114~489 字节，只是**状态快照**，
音乐在几 MB 的配套 ROM 里，必须跑对应主机的 CPU + 声音芯片才能出声。

> ⚠ **这句「做不到」是当时的结论，已经被推翻了。** 补上主机核之后（v5.3~v5.5），
> 这 494 个里能做的全做了。真正的判据不是「要不要模拟」，而是「有没有开源核
> 能用 zig 编成独立 exe」—— kode54 的 `audacious-xsf` 把 USF/2SF/SSF/DSF/GSF
> 全部凑齐了。

⚠ 顺带**纠正了上一轮（v5.2.6）的一个错误结论**：当时把 `.hwas`/`.swav`/`.dvi`
判成「容器解开了、负载编码没破」，故意不接进转换链路。**这个判断是错的** ——
不是格式特殊，是**自己的三个 bug 叠在一起**：

1. IMA 的步长索引表后半段写成了 `-2,-4,-6,-8`（应为 `2,4,6,8`）—— 半字节的 bit3
   只是**符号位**，幅度和 0~7 一样。写成负数会让负向半字节的 step 一路收缩到 0，
   delta 变成 `step>>3 = 0`，输出卡住 → **DC 漂移**（ac1=1.000、频谱质心 4 Hz）
2. HWAS 用了高半字节先（实际是低半字节先）
3. SWAV 按「每 36 字节一个帧头」解（实际只有文件开头一个 4 字节头）

教训写在 README ⚠58 里：`ac1 ≈ 1.0` 只能说明「解出来是慢变信号」，**不能**说明
「编码不是 ADPCM」。**先怀疑自己的实现，再怀疑格式。**

✅ **转不了的时候，现在会说清为什么了**（v5.2.6）：以前下载页只有一句
「包里没有本工具能直接转换的音源（.minigsf、.m3u）」—— 把扩展名一列了事，
用户既不知道是自己下错了、还是程序漏了、还是本来就不行。现在按格式给原因：

    48 个转不了：48 个 .minigsf（GBA 内存快照，每首仅 249~268 字节 —— 得跑 GBA 的 CPU 与声音芯片）
    14 个转不了：14 个 .dsf（Dreamcast 整包 rip，每首约 1.3 MB —— 得跑 ARM7 与 AICA）
    54 个转不了：54 个 .psf2（PS2 内存快照，得跑 Emotion Engine 与 SPU2）

> ⚠ 上面是 v5.2.6 的**文案样例**，这三种格式现在都能转了。今天实际会说「转不了」
> 的只剩 **5 种采样库**（`.gsflib`/`.usflib`/`.2sflib`/`.ssflib`/`.dsflib`）
> 加 **4bit AIFF**（XA-ADPCM，Road Rash 那类）—— 3DO 的 `.aif` 从 v5.6 起也通了。

播放列表 `.m3u` 不算进「转不了」的计数（它本来就不是音频）。**部分能转的包也会
说一句**（GBA 包是 10 个 `.mod` + 121 个 `.minigsf`，以前那 121 首一声不响地
消失，看着像程序漏了）。手动「添加文件夹」那条路也改了 —— 以前回「文件夹里
没有可识别的音源」，现在同样给原因。

✅ **换机依赖审计做完了，找到一个真 bug**（v5.2.5）：之前「换台电脑、下载完

## 临时文件放哪（v4.44 起）

程序运行时的临时 PCM 落盘默认在 **`D:\MSU1Temp`**，不再往 C 盘 `%TEMP%` 写。
优先级：环境变量 `MSU1_TEMP` > `D:\MSU1Temp` > 系统 temp（D 盘不可用时自动回落）。
启动时会自动清掉该目录下 24 小时前的旧残留，被强杀留下的也会回收。

## 首次运行注意
云盘登录态存于 `%LOCALAPPDATA%\MSU1Converter\`（`netease.json` + `browser/`），
**不在这个包里**，换机后需要重新登录一次 —— **Web 版自己就能登**（v5.2）：

点「上传云盘」→ 没登录会直接弹出登录窗，三页任选：
- **浏览器登录**（推荐）：开一个独立浏览器窗口，在里面正常登录一次即可。
  走的是网易云官方网页流程，不触发 8821 风控；登录一次长期复用。
- **粘贴 Cookie**：浏览器登录不可用时的兜底。
- **扫码**：可能被 8821 风控拦，撞上了会自动切到「粘贴 Cookie」页。

账号管理（切换账号 / 退出登录）在**上传对话框顶部那一行**，不用再开旧版。
详见 README ⚠34。

Web 版还会在 `%LOCALAPPDATA%\MSU1Converter\edge_profile\` 放一份独立的 Edge
配置目录（约 30MB，保证不复用你已开的 Edge 窗口）。删掉无副作用，下次自动重建。

**PSF 的 BIOS 路径**记在程序目录的 `psf_bios.txt`（一行，写完整路径）；
程序目录不可写时退到 `%APPDATA%\RetroMusic Lab\psf_bios.txt`。
